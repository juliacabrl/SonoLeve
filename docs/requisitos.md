# REQUISITOS FUNCIONAIS

RF01 — O sistema deve permitir visualizar o checklist de higiene do sono.  

RF02 — O sistema deve permitir marcar e desmarcar os itens do checklist.  

RF03 — O sistema deve permitir iniciar o exercício de respiração 4-7-8.  

RF04 — O sistema deve permitir reproduzir sons de relaxamento.  

RF05 — O sistema deve permitir iniciar e interromper os sons de relaxamento.  

RF06 — O sistema deve permitir registrar a quantidade de horas dormidas.  

RF07 — O sistema deve permitir avaliar a qualidade do sono de 1 a 5 estrelas.  

RF08 — O sistema deve permitir consultar os registros anteriores de sono.  

RF09 — O sistema deve permitir editar um registro de sono.  

RF10 — O sistema deve permitir excluir um registro de sono.  

RF11 — O sistema deve apresentar um gráfico semanal dos registros de sono.  

RF12 — O sistema deve apresentar dicas de higiene do sono.  

RF13 — O sistema deve alterar a paleta de cores dentro do horário estipulado.
