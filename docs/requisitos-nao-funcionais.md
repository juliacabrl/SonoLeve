# Requisitos Não Funcionais

- **RNF01 — Usabilidade:** as principais funções devem ser acessadas em até três interações.
- **RNF02 — Interface:** o aplicativo deve possuir uma interface simples e objetiva.
- **RNF03 — Modo escuro:** o modo escuro deve ser utilizado como padrão.
- **RNF04 — Funcionamento offline:** respiração e sons de relaxamento devem funcionar sem internet.
- **RNF05 — Desempenho:** o aplicativo deve responder rapidamente aos comandos do usuário.
- **RNF06 — Compatibilidade:** o aplicativo deve funcionar nos smartphones e sistema operacional definidos para o projeto.
- **RNF07 — Armazenamento:** os registros de sono devem ser armazenados localmente sempre que possível.
- **RNF08 — Privacidade:** os dados do usuário devem ser tratados de acordo com a LGPD.
- **RNF09 — Exclusão de dados:** o usuário deve poder excluir seus registros de sono.
- **RNF10 — Bateria:** o aplicativo deve evitar consumo excessivo de bateria.
- **RNF11 — Iluminação:** a interface deve evitar brilho e cores muito intensas durante o uso noturno.
- **RNF12 — Áudio:** os sons devem ser leves e compactados para permitir o uso offline e reduzir o consumo de recursos.
