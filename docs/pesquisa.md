# 02 - PESQUISA
 
## 2.1 INFORMAÇÕES PERTINENTES
 
- Pesquisas indicam que jovens adultos, principalmente os que conciliam estudos e trabalho, podem desenvolver problemas relacionados ao sono;
- Fatores socioeconômicos afetam diretamente a qualidade do sono;
- É importante considerar que uma parcela das pessoas que irá usar o aplicativo não dispõe de tempo para organizar uma rotina de sono como indicado pelos médicos.
 
## 2.2 NECESSIDADES E DIFICULDADES
 
### 2.2.1 NECESSIDADES
 
- Criar uma rotina de sono;
- Melhorar hábitos;
- Acompanhar a qualidade do sono;
- Relaxar;
 
### 2.2.2 DIFICULDADES
 
- Falta de tempo;
- Manter sono;
- Pressão Profissional;
- Cansaço contínuo;
- Dificuldades para organizar uma rotina de sono;
 
## 2.3 DADOS IMPORTANTES
 
- 1 a cada 3 adultos sofrem com insônia;
- 72% dos brasileiros sofrem com algum distúrbio do sono;
 
## 2.3 DESCOBERTAS IMPORTANTES
 
- Acordar muitas vezes durante a noite pode estar relacionado à uma série de distúrbios do sono. Dessa forma, vale considerar se não será importante uma opção para que o usuário informe quantas vezes acordou durante a noite.  
  Obs.: É importante tomar cuidado com essa funcionalidade para que ela não induza o usuário a acessar o software no meio da noite, o que poderia gerar estímulos desnecessários;
 
- Mulheres tendem a dormir menos que homens. Esse ponto é importante para a análise de possíveis usuários do software;
 
- A iluminação é um dos fatores que podem afetar diretamente o sono. O design e configuração da paleta de cores se torna um dos fatores críticos do sistema.
