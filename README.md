# SonoLeve

## App SonoLeve - Estudo de caso

### Descrição

O SonoLeve é um aplicativo voltado para higiene do sono e relaxamento. A proposta é auxiliar pessoas com dificuldades para dormir a melhorar seus hábitos de sono, utilizar técnicas de relaxamento e acompanhar a qualidade do descanso.
